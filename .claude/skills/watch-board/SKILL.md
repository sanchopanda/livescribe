# watch-board — фоновый опрос доски (session-only)

Опрос живёт **только в этой сессии Claude Code** (крон session-only, умирает при выходе). После
включения компа / нового старта Claude — запускать заново этим скиллом. Нужны локальные креды
`~/.skribo-vikunja.env` и локальная сессия (диалог показывается в терминале).

Состояние «что уже видели» — в `~/.skribo-vikunja-seen.txt` (список task id; переживает
перезагрузку). Механику доски брать из скилла `task-board` (Vikunja REST API).

## Шаги при запуске

1. **Догнать пропущенное за офлайн.** Сразу проверь доску: получи id всех задач проекта Skribo
   (`GET $VIKUNJA_URL/api/v1/projects/5/tasks`, JWT по логину из `~/.skribo-vikunja.env`, curl с
   `dangerouslyDisableSandbox`), сравни с `~/.skribo-vikunja-seen.txt`. Если появились **новые**
   (за время, пока опрос не работал) — коротко перечисли и запусти `check-tasks`. Затем перезапиши
   seen-файл текущим списком id. Если файла нет — создай его текущим списком (baseline, без уведомления).

2. **Поставить рекуррентный опрос.** `CronCreate` (загрузить через ToolSearch `select:CronCreate`):
   - `cron`: `11,41 * * * *` (каждые ~30 мин, не на :00/:30 и не в такт с opros expeditor-доски);
     `recurring: true`;
   - `prompt`: «Тихая проверка доски Skribo в Vikunja на новые карточки. Через task-board
     (креды `~/.skribo-vikunja.env`) залогинься и получи id всех задач проекта 5
     (`GET /api/v1/projects/5/tasks`), сравни с `~/.skribo-vikunja-seen.txt`, перезапиши файл
     текущим списком. Если новых НЕТ — ничего не пиши пользователю. Если ЕСТЬ — коротко перечисли
     (название + колонка) и запусти скилл check-tasks. curl — с dangerouslyDisableSandbox; токен/пароль
     не выводить.»

3. **Подтвердить кратко:** опрос поставлен (job id), каденс ~30 мин, session-only (умрёт при выходе,
   перезапускать `/watch-board`), крон авто-истекает через 7 дней, отмена — `CronDelete <job>`.

## Остановить
`CronDelete <job id>` (или сказать «останови опрос доски»).
