# proceed — один проход по задаче

Оркестратор рабочего цикла. Делает **ровно одну задачу** за вызов, затем отчитывается и
останавливается (ждёт следующего «продолжай»).

## Подготовка

Прочитать `docs/PROGRESS.md`, `docs/backlog.md`, `AGENTS.md`, `docs/KNOWLEDGE.md`.

## Шаг 0. Сверка с реальностью (перед выбором)

Истина статуса = состояние git. Сверить и починить дрейф:
- Пройтись по последним коммитам `main` (`git log --oneline -20`).
- Задачи бэклога, которые фактически сделаны (код в `main`), но не отмечены `[x]` —
  отметить сделанными; частично сделанные — пометкой в `PROGRESS.md`, что осталось.
- Если что-то поправили — кратко сообщить владельцу.

## Шаг 1. Выбрать задачу

Из `docs/backlog.md`:
- **Если есть «Задача в работе» в `PROGRESS.md`** → довести её.
- **Иначе** → верхняя незакрытая `LS-NN` по приоритету фаз (не уходить в позднюю фазу, пока
  есть незакрытые в текущей), с учётом подсказки «Следующее» в `PROGRESS.md`.

Озвучить выбранную задачу и строку обоснования. Если выбор реально неоднозначен и цена
ошибки высока — спросить владельца; иначе выбрать и продолжить.

## Шаг 2. Взять в работу

Записать задачу в `PROGRESS.md` (раздел «Задача в работе»: id / ветка, если заводили / статус).

## Шаг 3. Реализовать

Запустить скилл **`implement-task`** (стек-правила репо, TDD для логики, обновление доков).

## Шаг 4. Проверить

Запустить скилл **`test-task`** (типы/сборка + реальный прогон для поведения). Если красное —
вернуться к `implement-task` и починить. Повторять до зелёного.

## Шаг 5. Ревью

Запустить скилл **`review-task`**. Критичные замечания — починить (снова `implement-task`/
`test-task`), пока не чисто.

## Шаг 6. Зафиксировать

- Коммит(ы) по смыслу **прямо в `main`** и пуш (PR не обязателен — второго ревьюера нет;
  ветка только при изоляции). Сообщение — conventional-commits + трейлер `Co-Authored-By`.
- Отметить задачу `[x]` в `docs/backlog.md`.

## Шаг 7. Сохранить состояние и отчитаться

- Обновить `docs/PROGRESS.md`: «Сделано», «Следующее», «Задача в работе» = нет.
- Коммитнуть `PROGRESS.md`/`backlog.md`.
- Отчёт владельцу: что сделано, как проверено, следующий кандидат. **Остановиться** — ждать
  следующего «продолжай».

## Правила

- Одна задача за проход. Не начинать следующую без нового «продолжай».
- Всё по стандартам `AGENTS.md`. Секреты/`.env`/`dist` — не коммитить.
- Если задача заблокирована (нужен ответ владельца, недоступен ресурс) — не выдумывать:
  описать блокер, вернуть статус, обновить `PROGRESS.md`, спросить.
