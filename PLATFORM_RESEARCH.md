# Universal Platform Speaker Tracking Research

## Цель

Понять, как различные платформы видеозвонков (Teams, Пачка, Meet, Zoom) подсвечивают активного спикера в DOM, чтобы реализовать автоматическое определение говорящего.

## Поддерживаемые платформы

- ✅ **Microsoft Teams** - teams.microsoft.com
- ✅ **Пачка** - pachca.com
- ✅ **Google Meet** - meet.google.com
- ✅ **Zoom** - zoom.us
- ✅ **Другие** - универсальный fallback для неизвестных платформ

## Инструкция по использованию

### 1. Подготовка

```bash
# Собрать расширение с исследовательским модулем
npm run build:extension

# Или запустить в dev режиме
npm run dev:extension
```

### 2. Установка в Chrome

1. Открыть `chrome://extensions`
2. Включить "Developer mode"
3. Нажать "Load unpacked"
4. Выбрать папку `packages/extension/dist`

### 3. Запуск исследования

#### Для Microsoft Teams:
1. Открыть https://teams.microsoft.com
2. Открыть DevTools (F12)
3. Запустить `startTracking()` В КОНСОЛИ
4. Присоединиться к звонку

#### Для Пачки:
1. Открыть https://app.pachca.com (или ваш корпоративный домен)
2. Открыть DevTools (F12)
3. Запустить `startTracking()` В КОНСОЛИ
4. Присоединиться к видеозвонку

#### Для других платформ:
Аналогично - открыть платформу, DevTools, `startTracking()`, присоединиться к звонку

### 4. Основные команды

```javascript
// ОБЯЗАТЕЛЬНО запусти ДО начала звонка!
startTracking()

// Показать информацию о текущей платформе
getCurrentPlatform()

// Найти все элементы участников
findParticipants()

// Посмотреть собранные логи
getLogs()

// Логи по типам (добавлено/удалено/изменено)
getLogsByType()

// Экспортировать в JSON
const json = exportLogs()
console.log(json)
// Скопируй и сохрани в файл

// Очистить логи
clearLogs()

// Остановить трекинг
stopTracking()
```

## Что ищет скрипт

Скрипт автоматически адаптируется под каждую платформу и отслеживает:

### 1. Изменения CSS классов
Ключевые слова: `active`, `speaking`, `highlight`, `border`, `selected`, `focus`, `current`, `talking`

**Примеры:**
- Teams: `.participant-tile.active-speaker`
- Пачка: `.video-participant.speaking`
- Meet: `.participant-active`

### 2. Изменения стилей
- `border` - рамка вокруг говорящего
- `outline` - обводка
- `box-shadow` - тень/свечение
- `background` - фон

### 3. ARIA атрибуты
- `aria-label` - может содержать "Name, speaking"
- `aria-current` - текущий активный
- `aria-selected` - выбранный

### 4. Data атрибуты
- `data-tid` (Teams)
- `data-participant-id` (Meet)
- Любые `data-*` атрибуты

### 5. Структура участников
Платформо-специфичные селекторы:
- **Teams:** `[data-tid*="participant"]`, `.participant-tile`, `.video-tile`
- **Пачка:** `[class*="participant"]`, `[class*="member"]`, `[class*="video"]`
- **Meet:** `[data-participant-id]`, `[data-self-name]`
- **Zoom:** `[class*="video-avatar"]`, `[class*="attendee"]`

## Анализ результатов

После сбора данных обрати внимание на:

### 1. Повторяющиеся паттерны
- Один и тот же класс добавляется каждый раз при смене спикера
- Стиль меняется одинаково для всех говорящих
- ARIA атрибут обновляется предсказуемо

### 2. Стабильность селекторов
- Используются ли `data-tid` или другие стабильные идентификаторы?
- Или только CSS классы (могут меняться при обновлениях)?

### 3. Извлечение имени
- Где хранится имя участника? (aria-label, innerText, data-атрибут)
- Насколько легко его извлечь?

### 4. Тайминги
- Сколько времени между сменой спикера и обновлением DOM?
- Есть ли задержка?

## Troubleshooting

### ❌ Скрипт не загружается
- Проверь: `npm run build:extension`
- Перезагрузи расширение в `chrome://extensions`
- Обнови страницу платформы
- Проверь консоль на ошибки компиляции

### ❌ Нет логов при разговоре
- Убедись что запустил `startTracking()` ДО звонка
- Проверь что платформа определилась: `getCurrentPlatform()`
- Попробуй `findParticipants()` - видит ли скрипт участников?
- Очисти фильтры в консоли (не должно быть фильтра по уровням)

### ❌ Слишком много логов
- Это нормально! Скрипт логирует всё подозрительное
- Обращай внимание на паттерны которые **повторяются** при смене спикера
- Используй `clearLogs()` чтобы начать заново с чистого листа
- Фильтруй по emoji: 🔄 (изменения), ➕ (добавления)

### ❌ Платформа определилась неправильно
- Запусти `getCurrentPlatform()` - покажет какая платформа определена
- Если ошибка - напиши URL и я добавлю правильный паттерн

## Полезные советы

💡 **Для Teams**: Обрати внимание на `data-tid` атрибуты - они стабильнее CSS классов

💡 **Для Пачки**: Проверь есть ли уникальные ID у элементов участников

💡 **Для всех**: Border/outline изменения - самый надёжный визуальный индикатор

## FAQ

**Q: Можно ли использовать для других платформ?**
A: Да! Скрипт универсальный. Если нужная платформа не в списке, он использует fallback паттерны.

**Q: Скрипт влияет на производительность звонка?**
A: Минимально. Он только наблюдает за DOM, не изменяет его.

**Q: Можно ли оставить скрипт включённым постоянно?**
A: Да, но лучше использовать только для исследования. Для production будет отдельный оптимизированный модуль.

**Q: Что если паттерн сломается после обновления платформы?**
A: Повторно запусти исследование и найди новый паттерн. Именно поэтому важно документировать стабильность.
