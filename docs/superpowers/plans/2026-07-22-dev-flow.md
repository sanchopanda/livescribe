# LiveScribe dev-flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a repeatable development flow in livescribe — local task tracking, documentation conventions, and release notes — ported and adapted from the `../expeditor` harness.

**Architecture:** Five `.claude/skills/` (proceed orchestrator + thin implement/test/review wrappers + release), a `docs/` scaffold (backlog, PROGRESS, CONVENTIONS, KNOWLEDGE, README, decisions/, specs/), a `CHANGELOG.md`, and an AGENTS.md "flow" section. Skills are markdown with YAML frontmatter; the thin wrappers delegate to built-in skills (`superpowers:test-driven-development`, `/code-review`, `/verify`, `/run`).

**Tech Stack:** Markdown skills/docs. Reference source: `/home/aleksander/code/expeditor/.claude/skills/*` and `/home/aleksander/code/expeditor/docs/*`. Target repo: `/home/aleksander/code/livescribe` (npm workspaces; Chrome extension MV3 + Vite/React; Fastify/WS backend; STT = Deepgram only).

## Global Constraints

- Task IDs: prefix `LS-` + number (LS-01, LS-02, …).
- Tasks tracked ONLY in `docs/backlog.md` + `docs/PROGRESS.md`. No GitHub Issues/Projects.
- Commit **directly to `main`** (repo practice); branch only when isolation is needed. No mandatory PR.
- Release model: single monorepo semver version in root `package.json`; tag `vX.Y.Z`; GitHub Release + `CHANGELOG.md` (Keep a Changelog).
- Skill files: `.claude/skills/<name>/SKILL.md` with YAML frontmatter (`name`, `description`).
- Doc filenames: kebab-case latin; Russian prose, English identifiers.
- Никаких секретов/`.env`/`dist`/`node_modules` в индексе.
- Verify claims before asserting done (fold the "verify before you call me to look" rule into `test-task`).

## File Structure

- Create `.claude/skills/proceed/SKILL.md` — orchestrator, one task per pass.
- Create `.claude/skills/implement-task/SKILL.md` — thin coding wrapper with stack rules.

- Create `.claude/skills/review-task/SKILL.md` — thin review wrapper (`/code-review` + checklist).
- Create `.claude/skills/release/SKILL.md` — CHANGELOG + tag + GitHub Release.
