## LS-17 — тайминги + поиск в транскрипте (клиентское, быстрый win)

**Где:** `packages/admin/src/pages/MeetingDetailPage.tsx` (+ его `*.module.scss`). Только фронт —
сегменты уже приходят с `tsMs` в `MeetingDetailDTO.segments`.

**Что делаем:**
1. **Тайминги.** Перед каждой репликой показывать `mm:ss` (из `tsMs`, `tsMs/1000` → формат). Хелпер
   `formatTs(ms)` в `lib/format.ts`. Стиль — приглушённый моноширинный, как метка времени у Tactiq.
2. **Поиск в транскрипте.** Инпут «Поиск в транскрипте» над лентой; по вводу — фильтрация/подсветка
   реплик, где `text` содержит запрос (регистронезависимо, клиентски, сегменты уже загружены).
   Пусто найдено → «Ничего не найдено». Очистка возвращает полный транскрипт.

**Границы:** без hover-действий на репликах (закладка/хайлайт/задача — позже), без серверных
изменений. Матч по подстроке (не по границе слова) — достаточно для поиска.

**Критерии:** у реплик видны тайминги; ввод в поиск фильтрует/подсвечивает; очистка сбрасывает;
`type-check` + сборка admin зелёные.

## LS-16 — глобальный поиск по встречам (страница + бэкенд)

**Где:** новая страница `packages/admin/src/pages/SearchPage.tsx` + публичный-в-кабинете роут
`/search` (внутри `ProtectedRoute`/`CabinetLayout`) + пункт сайдбара «Поиск»; бэкенд — расширить
поиск встреч по **содержимому транскрипта**, не только по названию.

**Бэкенд:** сейчас `GET /api/meetings?q=` матчит только `title` (contains, insensitive). Расширить:
встречи, где `title` матчит **ИЛИ** есть `TranscriptSegment` с `text` содержащим `q` (user-scoped).
Опционально вернуть короткий сниппет совпадения. Вариант реализации — отдельный
`GET /api/meetings/search?q=` или флаг к существующему; определим в плане. Индекс/производительность
— на текущих объёмах `contains` достаточно; полнотекстовый поиск Postgres — follow-up.

**Фронт:** страница `/search` в духе `tactiq-search.png` — крупный инпут, empty-state с подсказками
(«ищите по названию, участникам, содержимому»), результаты = карточки встреч (как в списке) +
сниппет совпадения, клик → `/meetings/:id`. Состояния загрузки/пусто/ошибка.

**Границы:** поиск по названию + тексту транскрипта (MVP); участники/лейблы/сохранённые фильтры —
follow-up (у нас пока нет лейблов и имён участников как отдельного поля — только `speaker` в
сегментах). Без Postgres FTS на старте.

**Критерии:** `/search` доступен из сайдбара; запрос находит встречи по названию и по словам из
транскрипта; клик открывает встречу; `type-check` + сборки зелёные; бэкенд-запрос user-scoped.
