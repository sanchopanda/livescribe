# Дизайн: триггер-слова → подсветка в расширении (LS-14)

Дата: 2026-07-27
Статус: согласован (ожидает вычитки спеки)

## Контекст и цель

В расширении встроенный content-виджет уже показывает живой транскрипт звонка (реплики по
спикерам, из offscreen → service-worker → `content.ts`). Хотим: пользователь задаёт
триггер-слова (напр. своё имя), и когда они звучат — расширение **подсвечивает** (без
нотификаций). Чисто клиентская фича: без бэкенда и LLM.

## Согласованные решения

1. **Подсветка:** конкретная реплика с триггером подсвечивается в списке (акцент `#0d9488`) +
   весь виджет коротко **пульсирует ~1с**, чтобы поймать внимание.
2. **Редактирование триггеров — в самом виджете** (там же, где транскрипт).
3. **Матч по финальным репликам**, регистронезависимо, **по границе слова** (чтобы «Аня» не
   ловилась в «компания»). Без desktop-нотификаций (опция на будущее).
4. Хранение триггеров — `chrome.storage.local` (`skriboTriggers: string[]`), глобально.

## Архитектура (всё в `packages/extension/src/content/content.ts` + стили виджета)

- **Хранилище:** `chrome.storage.local` ключ `skriboTriggers` (массив строк). Требует
  permission `"storage"` — он уже есть (добавлен в LS-11). Загрузка при инициализации виджета;
  сохранение при изменении списка.
- **UI в виджете:** секция «Триггеры» рядом с транскриптом — инпут «добавить слово» (Enter/
  кнопка) + список добавленных с крестиком-удалением. Пустые/пробельные игнорируются, тримятся,
  дедуп (case-insensitive).
- **Детект:** при добавлении **финальной** реплики (`appendTranscriptReplica` / точка, где
  финальный транскрипт попадает в `transcriptReplicas`) — проверить текст против триггеров.
  Матч: `new RegExp('(^|\\P{L})' + escapeRegExp(trigger) + '($|\\P{L})', 'iu')` (границы по
  не-буквенным символам, Unicode-aware для кириллицы). На partial-репликах НЕ триггерим.
- **Подсветка:**
  - у сматченной реплики — флаг `highlighted`; при рендере ей добавляется CSS-класс
    (акцентный левый бордер + лёгкий фон). Остаётся в ленте.
  - весь виджет получает класс-вспышку (`skribo-trigger-flash`) на ~1с (CSS-анимация свечения),
    затем класс снимается.
- **Без бэкенда/LLM.** Не трогаем WS/offscreen/service-worker/audio.

## Границы (YAGNI)

- Без desktop-нотификаций (только визуально) — опция на будущее.
- Без матча по partial (только финальные) — избегаем мигания.
- Без регэкспов/вайлдкардов в триггерах пользователя — простые слова/фразы.
- Быстрое саммари — отдельная фича (LLM/LS-09), не здесь.

## Критерии готовности

- В виджете есть секция триггеров: добавить/удалить, список персистится в `chrome.storage.local`.
- Когда финальная реплика содержит триггер (по границе слова, регистронезависимо) — реплика
  подсвечена и виджет коротко пульснул.
- Обычные реплики без триггеров — без подсветки; partial не триггерит.
- `npm run type-check` + `npm run build:extension` зелёные; поведение проверено в браузере
  (сид-триггер + транскрипт со словом → подсветка).
