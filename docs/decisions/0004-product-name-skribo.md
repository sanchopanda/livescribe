# 0004 — Продуктовое имя: Skribo

Статус: принято (2026-07-23)

## Контекст

Рабочее имя «LiveScribe» совпадает с существующим брендом **Livescribe** (умные ручки,
Anoto) — риск путаницы и товарного знака. Нужно своё имя. Ниша транскрипции/анализа
созвонов занята Otter, Fireflies, Fathom, Gong, Chorus, tl;dv — эти мотивы обходим.

## Решение

Имя продукта — **Skribo** (через `k`).

- Scribe-корень (латинско-эсперантское «пишу/письмо»), но отделён от бренда Livescribe.
- Написание через `k`, а не `c`: вариант `scribo` занят во всех нужных зонах
  (`scribo.ru/.io/.com`), а `skribo` свободен в `.ru`, `.io`, `.ai`. Плюс `k` — отчётливее
  и более «ownable» как марка. Произношение одинаковое («Скрибо»).
- Домены — см. ADR-0002: API сейчас `api.skribo.ru`, бренд-домен позже `skribo.io`.

## Объём ребрендинга

- **Сейчас (этот шаг):** пользовательское имя — manifest `name` → «Skribo»; строки логов;
  продуктовое имя в документации; этот ADR.
- **Отложено → LS-10 «Ребрендинг livescribe → Skribo»:** механическое переименование
  идентификаторов пакетов (`@livescribe/*` → `@skribo/*`), имя репозитория, алиасы в
  `vite.config`/`tsconfig`, оставшиеся упоминания в коде/доках. Делается одним
  отревьюенным проходом, чтобы не оставлять полу-переименованное состояние.

## Последствия

- Внешне продукт называется Skribo уже сейчас; внутренние идентификаторы `@livescribe/*`
  временно остаются до LS-10 (осознанное промежуточное состояние).

## Рассмотренные альтернативы

- `scribo` (через `c`) — отклонено: домены заняты, ближе к общему слову «scribe».
- `Skriba`, `Scripta`, `Skribe` — свободны хуже (заняты `.io`/`.ai`), менее удачны.
- Оставить «LiveScribe» — отклонено: коллизия с брендом Livescribe.
