### Блокеры подачи

- [ ] **Прод-ключ `OPENROUTER_API_KEY`.** Без него «Саммари встречи» в виджете и «Анализ»
      в кабинете отвечают 503 — ревьюер это увидит и кликнет. Альтернатива: спрятать кнопку
      саммари в store-сборке и не упоминать анализ в описании.
- [ ] **SMTP (`SMTP_*` + `APP_URL`) на проде.** Иначе «Забыли пароль?» — тишина, и

- [ ] **Тестовый аккаунт + test instructions** (см. раздел ниже) — без них стандартный

## Подготовка пакета

```bash
npm run pack:extension
```

Результат: `skribo-extension-<version>.zip` — версия берётся из `manifest.json` расширения.

## Аккаунт

- Chrome Web Store developer account.
- Разовый взнос $5 (единоразовая регистрационная плата разработчика).
- Верификация аккаунта разработчика (email/личность) — может потребовать дополнительное время до публикации.

## Обоснования прав (Permission justifications)

Готовые тексты для полей обоснования прав в Developer Dashboard:

- **`tabCapture`** — «Захват аудио активной вкладки для транскрипции звонка по явному действию пользователя (кнопка Start в виджете).»
- **`offscreen`** — «Offscreen-документ обрабатывает аудио и держит WebSocket к STT-бэкенду (service worker MV3 не держит долгие соединения).»
- **`scripting`** — «Внедрение виджета/контент-скрипта на страницах поддерживаемых платформ.»
- **`storage`** — «Локальное хранение токена аккаунта и настроек виджета (триггеры, размер/позиция).»
- **`alarms`** — «Таймеры keep-alive для активной сессии записи.»
- **`activeTab`** — «Доступ к текущей вкладке при запуске записи.»
- **Хосты** — «Домены Meet/Zoom/Teams/Pachca — для виджета; api/app.skribo.ru — связь с бэкендом и кабинетом.»

Отдельное обязательное поле дашборда — одно назначение расширения:

> Расширение выполняет одну задачу: транскрибирует в реальном времени аудио видеозвонка
> в активной вкладке и показывает текст пользователю.

## Тестовый аккаунт для ревьюера

Расширение без входа не работает, поэтому поле «Test instructions / login credentials» —
обязательное. Нужны:

- заведённый на проде (`https://app.skribo.ru`) тестовый пользователь: email + пароль
  (обычный аккаунт, отдельный от личного);
- шаги воспроизведения:
  1. Открыть попап расширения, войти по выданным email + паролю.
  2. Открыть `https://meet.google.com/` и начать/присоединиться к встрече.
  3. В виджете нажать **Start** — через несколько секунд идёт живой транскрипт.
  4. Открыть `https://app.skribo.ru` → «Переговоры» — встреча сохранена.

Указать, что аудио обрабатывается по явному действию пользователя (кнопка Start) и что
сырое аудио на сервере не хранится.

## Проверка store-сборки перед подачей

Проверять надо **именно** `dist-store` (у `dist/` другие права):

```bash
npm run pack:extension     # соберёт packages/extension/dist-store + zip
```

`chrome://extensions` → Developer mode → Load unpacked → `packages/extension/dist-store`.
Что смотреть: попап логинится; виджет появляется на Meet/Pachca; **Start** даёт транскрипт
(проверка суженных `web_accessible_resources` — грузится ли AudioWorklet); в консоли нет
ошибок permissions; встреча доезжает до кабинета.

## Unlisted как первый шаг

Можно подать на **Unlisted** (доступ по прямой ссылке): ревью то же самое, но без публичной
витрины, продающих скриншотов и риска ранних отзывов. Пройти пайплайн сейчас, переключить на
Public позже.
