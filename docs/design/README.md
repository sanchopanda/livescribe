# Дизайн-макеты

Визуальные макеты для выбора направления. Открываются как обычные файлы в браузере
(`file://`), самодостаточны: без внешних запросов, шрифтов и скриптов с CDN.

- [`admin-cabinet-design-options.html`](admin-cabinet-design-options.html) —
  четыре варианта дизайна кабинета (`app.skribo.ru`), 2026-08-04. Переключатель A/B/C/D,
  каждый вариант показан на списке переговоров и карточке встречи:
  - **A. Читальня** — сайдбар + одна колонка, журнал по дням, антиква в транскрипте,
    таймкод в левой колонке, саммари в шапке карточки. Акцент `#2C5470`.
  - **B. Пульт** — топбар + плотная таблица с сортировкой и фильтрами, шапка со
    статистикой встречи, моноширинные числа. Акцент `#B04A08`.
  - **C. Split-view** — рейл + колонка списка + панель встречи со вкладками
    (транскрипт / саммари / задачи). Акцент `#12604A`.
  - **D. Студия** — тёмная тема, сетка карточек с волной дорожки, цвет на спикера.
    Акцент `#E9A05C`.

  Данные в макетах придуманы, кнопки не нажимаются. Варианты сознательно остаются в своей
  палитре и не переключаются вместе с темой читателя.

Выбранный вариант оформляется дизайн-спекой в
[`../superpowers/specs/`](../superpowers/specs/) и планом в
[`../superpowers/plans/`](../superpowers/plans/); текущая спека кабинета —
[`2026-07-24-admin-cabinet-design.md`](../superpowers/specs/2026-07-24-admin-cabinet-design.md).
